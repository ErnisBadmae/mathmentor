# CISIA: исходный образец и подготовка тренировок

Проверено 2026-10-09. Несмотря на турецкое имя файла, внутри английский
`CISIA – TOLC-I Sample Test`, copyright 2021: 50 вопросов, 50 страниц.
Математика: вопросы 1–20, PDF страницы 3–16. Официальные ответы: страницы 49–50.

## Что подготовлено

- `extracted/mathematics.student.pdf`: исходные математические страницы без ключа.
- `extracted/manifest.json`: 50 ссылок на задания, разделы, страницы и SHA-256 источника.
- `extracted/page-*.pdf`: исходные страницы с заданиями, с сохранёнными формулами и рисунками.
- `extracted/answer-key.operator.json`: 50 ответов из таблицы самого документа.
- `extracted/source-text.txt`: текст для поиска; не использовать как точную запись формул.

Текстовый слой повреждает математические глифы, дроби и степени. Поэтому источником
задания остаётся PDF, а не автоматически переписанный текст. Для чтения использовать
также страницы с исходным passage, указанные в `context_pdf_pages` манифеста.
Манифест всех 50 вопросов остаётся реестром исходников. Для первых 20 математических
вопросов подготовлен бот-режим `/cisia`: оригинальные изображения, явная подпись
источника/номера/страницы, кнопки A–E, официальный ключ. Индивидуальные решения и
переводы не создавались; язык условий — английский, инструкции — русские.

Повторить извлечение:

```powershell
uv run --no-project --with pymupdf python data/CISIA/extract_source.py
```

Скрипт требует полного покрытия номеров 1–50 и полного официального ключа.
LLM/OCR для извлечения не используются; оплата токенов за этот этап отсутствует.
Сохранение исходных PDF-страниц избегает ошибок переписывания формул. Перед текстовым
импортом требуется сверка каждого условия, пяти вариантов и ключа по странице.

## Выбор исполнителя

Для этого небольшого PDF достаточно локального извлечения и проверки основным агентом.
Дополнительные облачные агенты увеличивают объём оплачиваемого контекста; экономия
по стоимости без замера не доказана. Локальный Qwen допустим для механического JSON
или fixtures с машинной приёмкой. Решения, математическая корректность, смысл перевода
и финальное одобрение требуют отдельной проверки; self-report Qwen ей не является.

## Формат подготовки

Первый импорт ограничен математикой по запросу ребёнка. Для остальных разделов и
экзаменационной подготовки уточнить вуз, программу, экзамен и язык. English TOLC-I
не следует автоматически считать актуальным пробником: с ноября 2025 English TOLC
заменены CEnT-S. Текущий банк и score events проекта относятся к ЕГЭ; результат этого
образца не должен автоматически менять балл ЕГЭ или закрывать темы.

Источники:

- https://www.cisiaonline.it/en/news/new-cent-s-here?page=0
- https://www.cisiaonline.it/en/tolc/tolc-i/structure-and-syllabus
- https://www.cisiaonline.it/en/cent/cent-s/structure-and-syllabus

Для первого занятия: небольшой самостоятельный блок без подсказок, затем разбор
ошибок по рассуждению, затем новые задачи на найденные пробелы и отложенная проверка.
При экзаменационной цели часть свежих заданий стоит сохранить для независимого среза.

## Бот и проверка

Подготовка оригинальных изображений: `uv run --no-project --with pymupdf python data/CISIA/prepare_math.py`.
Серверный пакет — `backend/data/cisia/`: 20 PNG и `math.json` с официальными ключами.
Этот JSON не отправляется ученику. Каждый PNG содержит один вопрос с вариантами.

Из `backend`: `python -m scripts.import_cisia` проверяет комплект и SHA-256 изображений;
`python -m scripts.import_cisia --apply` одобряет 20 задач и создаёт 20 миссий.
Повторный импорт не создаёт повторные миссии и не сбрасывает попытки.

Запуск в Telegram: `/cisia` или «CISIA · методичка». Ответ — кнопка A–E или одна
латинская буква. Непонятный ввод уточняется без failed evidence. После валидного
ответа результат 1/1 или 0/1 сохраняется, вопрос завершён; при ошибке показывается
правильная буква из ключа. Пропуск откладывает вопрос, `/cancel` выходит из режима.

Оценка детерминированная, `model_id=official-answer-key`,
`rubric_version=cisia-sample-2021-mcq-v1`. LLM не вызывается. Причина ошибки по букве
не назначается. Миссии не привязаны к темам ЕГЭ, не создают их повторы, не меняют
score events и исключены из банка обычных срезов. Это практика, без экзаменационных
штрафов и без сертификата/прогноза результата TOLC/CEnT-S.
